# Stellar Player — Trademark Policy

**Última actualización:** 2026

Este documento establece la política de uso de las marcas comerciales,
nombres comerciales y elementos de branding de **Stellar Busqueda**
(en adelante, "el Proyecto").

## 1. Marcas registradas

"Stellar Player", el logotipo de Stellar Busqueda, y cualquier otro nombre,
logotipo, eslogan o diseño asociado al Proyecto son marcas comerciales
del Proyecto. El uso no autorizado de estas marcas está prohibido.

## 2. Uso permitido

Se permite el uso de las marcas del Proyecto en los siguientes casos
sin necesidad de permiso explícito:

- **Atribución:** Mencionar que tu trabajo está basado en o utiliza
  Stellar Player, siempre que no sugieras respaldo o afiliación.
- **Distribución:** Incluir el nombre "Stellar Player" en listas de
  software, repositorios de paquetes o tiendas de aplicaciones para
  identificar el programa.
- **Copias modificadas:** Distribuir versiones modificadas del código
  fuente siempre que:
  - No utilices el nombre "Stellar Busqueda" como nombre del producto
    derivado.
  - Incluyas una nota visible indicando que se trata de una versión
    modificada.
  - No uses el logotipo oficial del Proyecto.

## 3. Uso prohibido

No está permitido sin autorización escrita:

- Usar "Stellar Busqueda" o variaciones como nombre de tu propio producto.
- Registrar dominios que incluyan "stellarplayer" o variaciones.
- Usar el logotipo del Proyecto en tu propio branding o sitio web.
- Modificar y redistribuir el logotipo oficial.
- Sugerir afiliación, patrocinio o respaldo por parte del Proyecto.
- Usar las marcas de manera que cause confusión en el mercado.

## 4. Branding en versiones modificadas

Si distribuyes una versión modificada del software:

- Debes eliminar o reemplazar los archivos de branding oficiales
  (logotipos, iconos de marca) contenidos en el directorio `resources/`.
- No puedes incluir el icono oficial de Stellar Player en tu versión
  modificada sin permiso explícito.
- La atribución "Basado en Stellar Busqueda" está permitida y alentada.

## 5. Uso comercial

El uso comercial de las marcas del Proyecto requiere un acuerdo por
escrito. Contactanos para discutir los términos.

## 6. Violaciones

El Proyecto se reserva el derecho de tomar las medidas legales
necesarias para proteger sus marcas comerciales.
